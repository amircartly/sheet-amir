# منظومة بطاقات مصرفية (AMIR) - إدارة الحجوزات والخزائن المالية

نظام سحابي متكامل لإدارة بطاقات مخصصات النقد الأجنبي للمواطنين (4,000 دولار)، ومتابعة دورة حياة البطاقة من لحظة الحجز والتوريد حتى السحب بالخارج وتوريد الأرباح لخزائن الدينار والدولار.

---

## 🌟 المميزات الرئيسية للمنظومة

1. **إدارة الخزائن المالية الحية (Treasury Management):**
   - **خزينة الكاش (دينار ليبي):** متابعة النقدية السائلة بالدرج مع خصم الإيداعات وتوريد مبيعات الدولار.
   - **حسابات المصارف (5 مصارف):** توزيع أرصدة المصارف المحلية (الأمان، الجمهورية، التجاري الوطني، الصحارى، شمال أفريقيا).
   - **خزينة الدولار ($ Cash Vault):** استقبال العملة الصعبة المسحوبة عبر مكاتب الصرافة بالخارج قبل بيعها.
   - **حساب صافي الأرباح المحققة اللحظية.**

2. **نموذج الإدخال الذكي:**
   - الحقول الأساسية: (اسم الزبون، الرقم الوطني 12 خانة، هاتف المركزي، المصرف، قيمة الإيداع، تاريخ الإيداع، تاريخ الحجز، رقم البطاقة 16 خانة، الرقم السري المحلي PIN، السري دولار، تاريخ الصلاحية، ملاحظات).
   - **نظام الحماية من الازدواجية (Anti-Duplicate):** تحذير فوري وبارز عند محاولة إيداع نفس الرقم الوطني أو البطاقة إذا كانت مودعة القيمة مسبقاً لمنع تكرار الصرف.
   - **حرية إضافة حقول جديدة:** إمكانية إضافة أي حقول مخصصة جديدة بنقرة زر في أي وقت.

3. **محرك المراحل والفلترة (State Machine Workflow):**
   - **محجوزة:** حجز المخصص المالي.
   - **مودعة:** تم توريد القيمة وخصمها من الخزينة.
   - **انتظار الشحن:** بانتظار شحن الرصيد من مصرف ليبيا المركزي.
   - **مشحونة:** تم شحن رصيد الـ 4000$ بنجاح.
   - **مرسلة للسحب:** إصدار رقم إشاري (Reference No) وتحديد مكتب الصرافة بالخارج.
   - **تم السحب والتصفية:** تحويل الرصيد لخزينة الدولار وبيعه بسعر السوق الموازي وتوريد صافي الربح لخزينة الدينار.

4. **البحث السريع بثلاثة معايير:**
   - البحث بالاسم.
   - البحث بالرقم الوطني.
   - البحث بالرقم السري (PIN المحلي أو السري دولار).

5. **الربط مع Google Drive و Google Sheets:**
   - تصدير ملفات Excel و CSV متوافقة 100%.
   - توفير كود Google Apps Script الجاهز لإنشاء التبويبات والمعادلات التلقائية على شيت جوجل.

## 🚀 التشغيل المحلي (Getting Started)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# أو البناء والتشغيل للإنتاج
npm run build
npm start
```
